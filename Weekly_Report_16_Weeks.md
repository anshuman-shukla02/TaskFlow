# Weekly Progress Report (16 Weeks)
**Project Title:** TaskFlow - Educational Productivity & Task Management Platform

This report outlines the 16-week development cycle of the TaskFlow platform (MERN stack).

---

### **Week 1: Project Initiation & Requirements**
*   **Activities:** Identified task management problems in education. Defined Admin, Faculty, and Student roles.
*   **Outcome:** Finalized project scope and core feature list.

### **Week 2: Architecture & UI/UX Planning**
*   **Activities:** Selected MERN stack. Drafted system architecture and low-fidelity UI wireframes.
*   **Outcome:** Approved system design and UI mockups.

### **Week 3: Database & Environment Setup**
*   **Activities:** Designed MongoDB schemas. Initialized Git repositories and Vite/Express environments.
*   **Outcome:** Database and dev environments fully operational.

### **Week 4: Authentication System**
*   **Activities:** Implemented JWT authentication and role-based access control (RBAC).
*   **Outcome:** Secure login system with protected routes established.

### **Week 5: Admin Dashboard**
*   **Activities:** Built Admin interface with full CRUD operations for user management.
*   **Outcome:** Admins can view stats and manage accounts.

### **Week 6: Project & Group Management**
*   **Activities:** Developed student group formation and project registration modules.
*   **Outcome:** Project registration logic integrated across stack.

### **Week 7: Core Task Management**
*   **Activities:** Built the faculty-to-student task assignment pipeline.
*   **Outcome:** Seamless flow of task assignments achieved.

### **Week 8: Mid-Term Evaluation**
*   **Activities:** Tested core systems, fixed routing bugs, and presented mid-term progress.
*   **Outcome:** Stable core ready for advanced features.

### **Week 9: Submissions & Reviews**
*   **Activities:** Added student submission portal (with image upload) and faculty grading interface.
*   **Outcome:** End-to-end task assignment and grading loop completed.

### **Week 10: Student Analytics Dashboard**
*   **Activities:** Built the Student Growth page with visual analytics and progress metrics.
*   **Outcome:** Interactive charts implemented on user dashboards.

### **Week 11: Attendance System**
*   **Activities:** Integrated daily attendance tracking with duplicate-entry prevention.
*   **Outcome:** Robust, automated daily logging system.

### **Week 12: AI Study Materials**
*   **Activities:** Developed AI chat assistant for course materials with history caching.
*   **Outcome:** Students can interact dynamically with AI study tools.

### **Week 13: UI Refinement**
*   **Activities:** Redesigned frontend with a modern "Claymorphism" and soft-shadow aesthetic.
*   **Outcome:** Highly engaging, premium user interface achieved.

### **Week 14: Bug Fixing & Database Constraints**
*   **Activities:** Resolved critical bugs and added cascade deletion for AI chat data.
*   **Outcome:** Consistent database state with zero orphan records.

### **Week 15: Final Testing & Deployment**
*   **Activities:** Conducted User Acceptance Testing (UAT) and safely pushed code to GitHub.
*   **Outcome:** Version-controlled, production-ready codebase deployed.

### **Week 16: Final Documentation**
*   **Activities:** Compiled the Minor Project Report and prepared presentation slides.
*   **Outcome:** Project documented and ready for final defense.
